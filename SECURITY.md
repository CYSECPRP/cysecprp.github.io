# Security policy

Thanks for helping keep this site and its visitors safe.

## Reporting a vulnerability

Please report security issues **privately** through GitHub's [Report a vulnerability](https://github.com/CYSECPRP/cysecprp.github.io/security/advisories/new) form. Don't open a public issue or pull request for a security problem.

A helpful report includes:

- what you found and where (page URL or file)
- the steps to reproduce it
- the impact you expect, plus any proof of concept

I'll acknowledge your report, keep you updated while I work on a fix and credit you once it's resolved, unless you'd rather stay anonymous.

## Scope

In scope:

- the live site at https://cysecprp.github.io/
- the source code and GitHub Actions workflows in this repository

Out of scope:

- GitHub Pages and Formspree infrastructure (please report those to GitHub or Formspree)
- denial of service, load testing or high-volume automated scanning
- social engineering and phishing
- reports without a demonstrated security impact, such as HTTP headers that GitHub Pages doesn't let sites configure

## Supported versions

Only the latest version on the `main` branch, which is what's live, receives security fixes.
